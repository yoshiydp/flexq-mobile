# FlexQ 動作確認テスト

テスター向けの全機能テストケース集です。画面ごと・機能ごとにケースを分けています。
上から順に実施すると、アカウント作成 → データ作成 → 各機能の確認、と自然な流れになるように並べています。

## はじめに

### 準備するもの

- **テスト端末**: iPhone(TestFlight)または Android(Google Play 内部テスト)。招待リンクからアプリをインストールしてください
- **音源ファイル**: mp3 または wav を 2〜3 曲、端末の「ファイル」アプリ(iOS)/「ダウンロード」フォルダ(Android)に入れておいてください
- **イヤホン**: 有線または Bluetooth(録音・同時再生のテストで使います)
- **環境**: マイクで録音するため、声を出せる場所で実施してください

### 結果の報告方法

- 各ケースの「期待される結果」と違う動きをしたら **NG** です
- NG の場合は「**ケース番号**(例: PE-10)+ 実際に起きたこと + 可能ならスクリーンショット/画面録画」を送ってください
- アプリが落ちた・固まった場合は、直前に何をしていたかを添えてください
- 「期待どおりだけど使いにくい・分かりにくい」という感想も大歓迎です(番号+コメントで送ってください)

### 時間がないとき(最低限チェック)

次の 10 ケースだけでも主要機能を一巡できます:
RG-03(登録)→ NP-05(プロジェクト作成)→ PE-01(編集・保存)→ CU-01(CUE)→ PR-05(トラックを聴きながら録音)→ RP-02(録音の保存)→ AI-02(AI クリーンアップ)→ TL-02(トラック追加)→ QM-05(メモ)→ PF-03(ログアウト)

## 9. CUE 機能(CU)

CUE は曲の好きな位置に付けられる「しおり」です。プロジェクト編集画面の Cue A〜E ボタンで操作します。

| No | 確認すること | 手順 | 期待される結果 |

## 13. トラック同時再生(SY)

プロジェクトの録音を、トラック(伴奏)と重ねて再生する機能です。録音の再生画面に「トラック同時再生」スイッチが表示されます。

| No | 確認すること | 手順 | 期待される結果 |
|----|----|----|----|
| SY-01 | イヤホンなし | イヤホンを外した状態でスイッチを見る | スイッチが無効で、「イヤホン(有線 / Bluetooth)接続時に使用できます」と表示されている |
| SY-02 | 同時再生 | イヤホンを接続してスイッチを ON → 再生 | 録音とトラックが重なって再生され、トラック専用の音量スライダーが現れる |
| SY-03 | タイミングのズレ | 同時再生中にシークバーで位置を移動する | 移動後も声とトラックのタイミングが合っている(ズレて聞こえない) |
| SY-04 | 声のみ + 同時再生 | AI クリーンアップ済みの録音で「声のみ」を選ぶ | イヤホンを外していてもスイッチを ON にできる |
| SY-05 | 声のみのタイミング | AI クリーンアップ済みの録音で「声のみ」を選び、同時再生を ON にして最初から再生する | 声とトラックのタイミングが合っている(声が一定時間遅れて聞こえたりしない)。「元の録音」で同時再生したときと同じタイミングで聞こえる。再生の冒頭で音が途切れ途切れ(カクつき)にならない。有線 / Bluetooth イヤホンのどちらでも同じ |
| SY-06 | 声のみ + シーク | 「声のみ」の同時再生中に、シークバーで位置を何度か移動する | 移動のたびに声とトラックのタイミングが合った状態で再生される |
| SY-07 | 切り替え後のタイミング | 同時再生中に「元の録音」⇔「声のみ」を切り替えて、同じあたりを聴き比べる | どちらでも声とトラックのタイミングが同じに聞こえる(切り替えでズレが生じない) |
| SY-08 | Bluetooth で録音したテイク | Bluetooth イヤホンを付けてトラックを聴きながら録音 → 保存 → 同時再生(有線・無線どちらでも) | 声がトラックより先に聞こえない(録音時の Bluetooth 遅延が補正される)。有線イヤホンで録音したテイクと同じタイミングに聞こえる |
| SY-09 | トラックの出だし | 同時再生を ON にして最初から再生・シークバーで途中から再生する | トラックの鳴り始めが引っかからず滑らかに出る(初回の同時再生 ON 時はトラックのダウンロード中にローディングが出る) |
| SY-10 | はじめから録音したテイク | REC MODE で「はじめから」を選んで録音 → 保存 → 同時再生 | 声とトラックのタイミングが合っている(トラックが先行して声が遅れて聞こえない)。途中から録音したテイクと同じ精度で合う |
